# Анализ работы агента

1. Запусти `npm run report` (по умолчанию за 7 дней; `-- --days 30` для большего периода).
   Если пользователь работает в mock-режиме, добавь `-- --mock`. Не читай `data/` напрямую.
2. Разбери отчёт и ответь по-человечески, коротко:
   - Какие ключевые слова приводят к черновикам и отправкам, а какие только тратят лимит поиска
     (500 запросов в неделю). Предложи, что убрать и какие похожие запросы добавить.
   - Подходит ли порог оценки: если почти всё «низкая оценка» — запросы слишком широкие;
     если много «не вошёл в лимит прогона» — можно поднять «Черновиков за прогон».
   - Что общего у пропущенных пользователем черновиков и у его правок перед отправкой.
     Это сигнал, что поправить в промпте `draftSystem` или `FILTER_SYSTEM` в `src/ai.js`.
   - Ошибки, если есть, и как их исправить.
3. Ключевые слова, порог и лимиты пользователь меняет сам в админке (раздел «Настройки»),
   потому что они хранятся в базе. Дай готовый список, который можно вставить.
4. Промпты меняются в коде. Покажи предлагаемое изменение и примени только после согласия,
   затем `npm run check && npm test`.

Название продукта в любых предложенных текстах — «WeArt Studio».
