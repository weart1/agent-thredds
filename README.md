# Агент WeArt Studio для Threads — с веб-админкой

> С чего начать: [STEPS.md](STEPS.md) — этапы запуска и что присылать Claude. Подробности к каждому шагу — [PLAN.md](PLAN.md).

Агент по расписанию ищет в Threads посты, где люди ищут AI-инструменты для картинок, видео,
музыки и т.п. Нейросеть (через Runware) оценивает каждый пост, по лучшим пишет ответ: сначала полезный совет,
потом честное упоминание WeArt Studio. Всё это видно в админке на вашем сайте.

## Что есть в админке

- **Очередь.** Пост и готовый ответ в виде ветки, как в Threads. Текст правится прямо в поле.
  Кнопки «Отправить», «Другой вариант», «Пропустить», переключатель ссылки и счётчик символов.
- **Что делает агент.** Живая лента всех шагов: какие запросы искал, сколько нашёл,
  сколько отсеял и почему, что написал, что отправлено, ошибки.
- **Оценки постов.** Каждый пост, который видела модель: оценка 0–10, тип запроса,
  причина и что с ним стало. По ней удобно подбирать ключевые слова и порог оценки.
- **Отправленные.** История ответов со ссылками на них в Threads.
- **Настройки.** Ключевые слова, описание WeArt Studio для агента, ссылка с UTM-метками
  и лимиты. Всё меняется без перезапуска.

В шапке видно состояние агента, расход лимитов Meta, время следующего поиска,
и есть кнопки «Найти посты сейчас», «Проверить упоминания», «Пауза».
Админка обновляется сама, перезагружать страницу не нужно.

## Работа в Claude Code

Проект готов к тому, чтобы дальше развивать его в Claude Code.

1. Распакуйте архив и сохраните проект в git (так любое изменение можно откатить):
   ```
   cd threads-agent
   git init && git add . && git commit -m "Агент WeArt Studio"
   ```
2. Откройте папку в Claude Code: в приложении Claude на компьютере (вкладка Code → выбрать папку)
   или в терминале командой `claude` внутри папки.
3. Скопируйте `CLAUDE.local.md.example` в `CLAUDE.local.md` и впишите адрес сервера и домен.
   Этот файл не попадает в git.

Что уже настроено:

- **CLAUDE.md** — Claude Code сразу знает, как устроен проект, как его запускать и проверять,
  и правила: продукт всегда «WeArt Studio», ничего не публиковать в настоящий Threads при разработке,
  не трогать токены.
- **Тестовый режим** `npm run dev:mock` — агент работает с фейковыми Threads и Claude,
  ключи не нужны. Пароль админки `mock-password`. Удобно смотреть изменения интерфейса.
- **Тесты** `npm test` — Claude Code прогоняет их после каждого изменения.
- **Защита секретов** — в `.claude/settings.json` запрещено читать `.env` и `data/`,
  а боевой запуск и подключение к серверу требуют вашего подтверждения.
- **Команда `/agent-report`** — разбирает реальные результаты агента: какие ключевые слова работают,
  что отсеивается, какие ответы вы пропускаете или правите, и что поменять в настройках или промптах.
- **Команда `/deploy`** — проверяет код тестами и выкладывает его на сервер, не трогая `.env` и базу.

Примеры просьб: «добавь в админку фильтр по ключевому слову в оценках»,
«сделай так, чтобы агент отвечал и на комментарии под моими постами», «/agent-report за 14 дней».

## Что понадобится

- Node.js 20 или новее
- Публичный аккаунт Threads, от имени которого будут ответы
- Аккаунт разработчика Meta (developers.facebook.com)
- Ключ Runware API (my.runware.ai) — через него работают модели для оценки и текстов
- VPS (DigitalOcean) для агента и API, Vercel для админки
- Два поддомена одного домена: `api-agent.weartstudio.io` (VPS) и `agent.weartstudio.io` (Vercel)

## 1. Приложение Meta и токен Threads

Названия пунктов в кабинете Meta периодически меняются, но порядок такой:

1. На developers.facebook.com создайте приложение со сценарием **Access the Threads API**.
2. Включите разрешения: `threads_basic`, `threads_content_publish`, `threads_manage_replies`,
   `threads_keyword_search`, `threads_manage_mentions`.
3. В ролях приложения добавьте свой Threads-аккаунт как **Threads Tester** и примите приглашение
   в самом Threads (Настройки → Аккаунт → Разрешения сайтов → Приглашения).
4. Сгенерируйте User Token в кабинете приложения (живёт 1 час).
5. Скопируйте `.env.example` в `.env`, впишите `THREADS_APP_ID` и `THREADS_APP_SECRET`, затем:
   ```
   npm install
   npm run token -- ВАШ_КОРОТКИЙ_ТОКЕН
   ```
   Полученный токен вставьте в `.env` как `THREADS_ACCESS_TOKEN`. Дальше агент продлевает его сам.

**Важно про поиск.** Пока Meta не одобрит `threads_keyword_search` через App Review, поиск,
скорее всего, будет находить только ваши собственные посты. Подавайте приложение на проверку сразу
(в описании: «поиск релевантных обсуждений и ответы от лица бренда с ручной модерацией»).
Упоминания и публикация ответов работают и до одобрения.

## 2. Остальное в .env

- `RUNWARE_API_KEY` — ключ с my.runware.ai. Модели задаются в `FILTER_MODEL` и `DRAFT_MODEL`.
- `ADMIN_ORIGIN` — адрес админки на Vercel, например `https://agent.weartstudio.io`.
- `ADMIN_PASSWORD` — пароль для входа в админку, минимум 10 символов.
- `SESSION_SECRET` — случайная строка:
  `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`

## 3. Запуск на своём компьютере

```
npm start
```

Откройте http://localhost:3000 и войдите с паролем.

## 4. Запуск на сервере (VPS)

Подойдёт любой VPS (Hetzner, DigitalOcean и т.п.) с Ubuntu.

```
# Агент
npm install -g pm2
pm2 start src/index.js --name threads-agent
pm2 save && pm2 startup
```

Админку обязательно открывать по https. Проще всего поставить Caddy, он сам получит сертификат.
Направьте домен на IP сервера и создайте `/etc/caddy/Caddyfile`:

```
api-agent.weartstudio.io {
    reverse_proxy localhost:3000
}
```

Затем `sudo systemctl reload caddy` и в `.env` поставьте `COOKIE_SECURE=true`, после чего
`pm2 restart threads-agent`.

В `.env` на сервере укажите `ADMIN_ORIGIN=https://agent.weartstudio.io`.

### Админка на Vercel

Импортируйте репозиторий в Vercel (настройки сборки уже в `vercel.json`), добавьте переменную
`API_URL=https://api-agent.weartstudio.io` и подключите домен `agent.weartstudio.io`.
Подробно — в [PLAN.md](PLAN.md).

Railway или Render тоже подойдут, но подключите постоянный диск для папки `data/`,
иначе после перезапуска пропадут история и настройки.

## Где что хранится

Всё в одном файле `data/db.json`: настройки, черновики, история, лента. Делайте его резервную копию.
Файлы `keywords.json` и `product.md` используются только при самом первом запуске,
потом всё редактируется в админке.

## Защита

- Вход по паролю, сессия на 14 дней, 5 неверных попыток блокируют вход на 15 минут.
- Неудачные попытки входа видны в ленте.
- Поисковики не индексируют админку.

## Защита от бана (уже встроено)

- Не больше 20 ответов в сутки (меняется в настройках).
- Одному человеку не чаще раза в 30 дней и не больше одного черновика в очереди.
- Ссылка ставится только тем, кто прямо ищет инструмент, её можно выключить у любого ответа.
- Название всегда «WeArt Studio»: даже если модель или вы напишете «WeArt», агент исправит.

Советы: первые 2–3 недели держите 10–15 ответов в день, отвечайте с аккаунта, у которого
есть свои живые посты, и следите в аналитике за меткой `utm_source=threads`.
